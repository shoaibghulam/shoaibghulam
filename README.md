# 💫 About Me

Hi 👋, I'm **Shoaib Ghulam**, a **Full-Stack Developer** with 8+ years of experience building production web, mobile, and desktop applications.

At **[SaveLife.AI](https://savelife.ai)** I build **[AizaMD](https://app.aizamd.ai)**, an ambient clinical documentation platform used by 1,000+ clinicians across 150+ specialties in 20+ countries, shipped from one Next.js codebase to web, iOS/Android (Capacitor), macOS/Windows (Electron), and a Chrome extension embedded in Epic, Cerner, and athenahealth. I also build MERN features and REST APIs for FDA-cleared radiology AI products (RadioViewAI, CXRDetectAI, NeuroICH, MammoSightAI).

- 🎓 MSc Data Science at **NUST MISIS, Moscow** (2024 – 2026)
- 🌍 Based in Moscow · open to remote roles and relocation
- 🤖 Daily user of Claude Code and AI-assisted development workflows
- 💬 Ask me about React / Next.js, Node, Django REST, Capacitor, Electron
